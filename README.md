# 24式简化太极拳 · 3D 人体演示教学

一个在浏览器中运行的太极拳教学软件。以 **24式简化太极拳** 为蓝本，用一个**半透明的三维人体**逐式演示，
解决"对着屏幕学武术，看不清、学不像"的问题：

- **人体解剖式演示人**：按成人标准比例建模，分三层——半透明皮肤、肌肉（胸大肌、三角肌、肱二头肌、股四头肌、腓肠肌等）、骨骼（头骨、脊柱、胸廓、骨盆、四肢长骨、髌骨等），每层都可以单独开关，皮肤透明度可调。从背后看也能看清前面的手。
- **像人的头部**：有眼睛、眉毛、鼻子、嘴、耳朵和动漫风格的刺猬头发型（原创造型）。
- **手指清晰可见**：每只手有五根可弯曲的手指，掌、拳、勾手一眼就能分清，换手型时手指会逐渐握拢或张开；“手部特写”视角会让镜头自动对准双手。
- **左右着色**：左手左脚偏蓝、右手右脚偏橙，不再分不清左右，可以关闭。
- **任意旋转视角**：鼠标拖动 / 手指滑动旋转，滚轮 / 双指缩放；一键切换 **背面（跟练）/ 正面 / 左侧 / 右侧 / 俯视（看步法）/ 手部特写**。
- **视角跟随转身**：演示人转身时镜头自动跟随，始终保持在背后等相对位置，方便跟练。
- **镜像**：面对面跟练时像照镜子一样。
- **单式教学**：一式一式地教。开启"分步讲解"时，每一步用**普通话语音**讲解，同时演示该步动作，讲完再进入下一步。
- **连贯演练**：从预备势到收势完整演示全套24式，自动播报式名。
- **讲解不遮挡人物**：画面上不显示字幕，讲到哪一步，右侧就高亮哪一步并自动滚动到可见位置；朗读要领、呼吸、心法时也会依次高亮对应段落。
- 每一式都有 **名称、动作做法（分步）、动作要领、呼吸、心法**，均可朗读。
- 手部轨迹、速度（0.4×～1.25×）、循环练习、进度拖动。

## 新版：分层教学 + 动作纠正（`v3/` 文件夹）

新版放在 `v3/` 文件夹里，现有版本保持不变。

- **分层教学**：① 基本功 → ② 单式教学 → ③ 连贯演练。
  基本功共 11 课：无极桩、浑圆桩（站桩）；掌、拳、勾（手型）；弓步、虚步、仆步与独立步（步型）；
  弓步与虚步转换、上步、退步、侧行步、扣脚与撇脚（步法）。每课都有动作要领、**常见错误**、呼吸和心法。
- **步法辅助**：地面显示这一步两脚应落的位置（蓝色左脚、橙色右脚脚印）和重心点（黄色），
  左上角实时显示"重心 左 70% · 右 30%"。很多初学者的问题出在步法和重心上，这样一眼就能看出来。
- **动作纠正（摄像头 + 姿态识别）**：用 MediaPipe 识别练习者的身体关键点，
  把膝、髋、肘、肩的角度、步幅和重心位置与演示人的标准动作对比，给出 0～100 的评分、
  两条最主要的纠正提示（例如"左腿再屈膝下沉一些""步子太小，脚再迈开一些""重心不对，把重心移到右腿"），
  并可语音提示。跟着播放练习时会自动容忍半拍到两拍的延迟；暂停时可对照当前姿势做"定式"练习。
  每一步的得分显示在右侧步骤旁，练完给出总评分和主要问题。
  开始时先自然站立 3 秒做校准，抵消摄像头角度和体型差异。视频只在本机浏览器中处理，不会上传。

### 如何使用动作纠正

摄像头和姿态识别模型需要通过"网址"打开页面，直接双击 `index.html` 打开时浏览器会限制加载本地模型文件：

- **推荐：GitHub Pages**。在仓库的 Settings → Pages 中选择本分支发布，
  然后用手机或电脑访问 `https://<用户名>.github.io/<仓库名>/v3/`。手机也能直接用。
- **本机**：在项目文件夹运行 `npx http-server .`，然后访问 `http://localhost:8080/v3/`。

姿态识别库和模型（约 18MB）已放在 `vendor/mediapipe/`，不依赖谷歌服务器，国内网络也能用。
双击打开时会尝试从网上加载模型（需要能访问 jsdelivr 和谷歌服务器）。

摄像头建议放在斜前方约 45°、2～3 米外、腰部高度，让全身（包括双脚）入镜。

## 使用方法

无需安装，直接用浏览器（推荐 Chrome / Edge）打开 `index.html` 即可。

也可以启动一个本地静态服务器：

```bash
npx http-server .   # 然后访问 http://localhost:8080
```

快捷键：`空格` 播放/暂停，`←` / `→` 上一式 / 下一式。

> 语音讲解使用浏览器自带的语音合成（Web Speech API）。若未检测到"中文（中国大陆）"语音，界面会提示，
> 文字讲解照常显示。Windows / macOS 可在系统设置中添加中文语音；Chrome 通常自带"普通话"语音。

## 调整动作

动作在 `js/forms.js` 中以关键帧描述，每一帧只写与上一帧不同的部分，例如：

```js
s.k(2.0, '重心前移成左弓步……', {
  w: 0.3,                // 重心：0=全在左脚，1=全在右脚
  yaw: 85, waist: 5,     // 胯的朝向、转腰角度（度，向左为正）
  lf: { pitch: 0 },      // 左脚：pitch>0 脚尖翘起，<0 脚跟离地
  rh: H(0.04, 0.2, 0.45, 'F', 'U'),  // 右手位置(右,上,前)，手心向前，指尖向上；第6个参数可写 'fist' 拳、'hook' 勾手
});
```

四肢由 IK 自动求解，因此只需要给出脚的位置和手的位置/朝向。
动作编排是依据24式的标准套路描述制作的示意动画，细节与名家示范难免有出入，欢迎按需微调。
